1. Run the application locally: `npm run dev`
2. Navigate to different pages and features
3. Take screenshots using your browser's developer tools
4. Save them in this folder with descriptive names

## Recommended Screenshot Tools

- Browser Developer Tools (F12)
- Screenshot extensions
- Online tools like Screenshot.rocks
- Built-in OS screenshot tools
